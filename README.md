# TypeScript Coding Practice for SDET Interviews 🚀

A practical collection of **50 TypeScript coding problems** focused on the problem-solving patterns commonly used in **SDET / Test Automation interviews**.

This repository is part of my preparation for **JavaScript/TypeScript-based automation roles**, with emphasis on writing clean logic, understanding core programming fundamentals, and solving problems without relying heavily on built-in methods.

---

## 🎯 Purpose

The goal of this repository is to strengthen the TypeScript fundamentals required for automation engineering, including:

- Problem-solving and logical thinking
- String manipulation
- Array manipulation
- Loops and conditions
- Frequency counting
- Searching and sorting
- Nested loops
- Stack / LIFO concepts
- Test-data generation
- Practical automation-oriented coding scenarios
